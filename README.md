# Eiki Murata — Profile

Static profile site for GitHub Pages. No build step is required.

## Publish

1. Push this directory to a GitHub repository.
2. Open **Settings → Pages** on GitHub.
3. Select **Deploy from a branch** and set the source directory to `/ (root)` on the target branch.

To preview the site locally, run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000` in a browser.
